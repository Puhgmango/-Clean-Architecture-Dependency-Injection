# Clean-Architecture-Dependency-Injection
- Nội dung: Phân chia lớp theo Clean Architecture (Presentation / Domain / Data); nguyên lý 
đảo ngược phụ thuộc (Dependency Inversion Principle); Repository Pattern & UseCase 
(Interactor); Dependency Injection với get_it và injectable / Riverpod; cơ chế khởi tạo và liên 
kết phụ thuộc (WidgetsBinding, MultiBlocProvider).
- Yêu cầu demo: Xây dựng ứng dụng đọc dữ liệu từ REST API theo kiến trúc 3 lớp rõ ràng; 
viết unit test cho tầng Domain với dependency được mock (abstract interface), chứng minh 
tầng Presentation không phụ thuộc trực tiếp vào Data Source.
